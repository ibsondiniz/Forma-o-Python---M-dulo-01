# Agenda de contatos em Python

Programa de terminal para gerenciar contatos: adicionar (nome, com telefone e e-mail opcionais), listar, editar, marcar ou desmarcar como favorito (★) e apagar. Os contatos ficam em memória enquanto o programa roda.

Desafio do módulo 1 de uma formação em Python, feito em 2024.

## Como rodar

Precisa de Python 3.

```bash
python Desafio_Agenda.py
```

Escolha a opção pelo número no menu.
